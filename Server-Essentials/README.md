
# Server Essentials – Windows Server & Linux Administration

## Overview
This repository contains practical assignments completed as part of the Server Essentials training program at TOPS Technologies.

The purpose of this module is to develop hands-on skills in Windows Server administration, Active Directory, networking services, virtualization, and Linux system administration.

## Technologies & Tools
- Windows Server 2025
- Windows 11
- VMware Workstation
- Active Directory Domain Services (AD DS)
- DNS and DHCP
- Group Policy (GPO)
- File Server (SMB, iSCSI)
- IIS and FTP
- Hyper-V
- Linux Server
- SSH

## Practical Assignments

### Windows Server Administration
1. Introduction to Windows Server
2. Peer-to-Peer and Client-Server
3. Active Directory and User Management
4. Group Policy (GPO)
5. DNS Server
6. DHCP Server
7. File Server (SMB, iSCSI)
8. Web Server (IIS, FTP)
9. Hyper-V

### Linux Administration
10. Introduction to Linux Server
11. Linux File System Hierarchy
12. Linux Command Line and Basic Commands
13. Scheduling in Linux
14. File Permissions
15. SSH Server
16. User Management

## Learning Objectives
- Understand Windows Server architecture.
- Configure and manage Active Directory.
- Manage users, groups, and organizational units.
- Configure DNS and DHCP services.
- Implement file and web server services.
- Understand virtualization.
- Perform Linux system administration.
- Manage Linux users, permissions, and remote access.

## Practical Evidence
Each assignment folder contains:
