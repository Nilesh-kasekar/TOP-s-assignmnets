
# CompTIA Network+ (N+)

## About This Repository
This folder contains my CompTIA Network+ study notes, networking assignments, practical labs, and troubleshooting documentation.

## Learning Objectives
- Learn networking fundamentals and protocols.
- Understand network devices and topologies.
- Practice IPv4, IPv6, and subnetting.
- Configure VLANs, DNS, and DHCP.
- Learn network security and maintenance.
- Troubleshoot connectivity using networking commands.

## Assignment Sections

### 01. Network Fundamentals and Building Networks
- Network devices and topologies
- OSI and TCP/IP models
- IP addressing and subnetting
- Routing and switching
- VLAN configuration
- DNS and DHCP
- Wireless networking and network cables

### 02. Network Security, Maintenance and Troubleshooting
- Network security fundamentals
- Firewalls and access control
- Network monitoring
- Network maintenance
- Troubleshooting methodology
- Ping, ipconfig, tracert, and nslookup
