
# Network Fundamentals and Building Networks

## Overview
This section contains practical assignments and notes about networking fundamentals, network devices, IP addressing, and network configuration.

## Topics Covered
1. Network devices and their functions
2. Network topologies
3. OSI and TCP/IP models
4. IPv4 and IPv6 addressing
5. Subnetting fundamentals
6. Routing and switching
7. VLAN configuration
8. DNS and DHCP
9. Wireless networking
10. Network cables and connectors

## Practical Labs
- Build a basic network in Cisco Packet Tracer.
- Configure IP addresses on PCs.
- Configure routers and switches.
- Test connectivity using ping.
- Practice VLAN configuration.
- Configure DNS and DHCP services.

## Tools
- Cisco Packet Tracer
- Windows Command Prompt
- Windows PowerShell

## Documentation Format
Each task includes the objective, theory, practical steps, commands, results, and conclusion.
