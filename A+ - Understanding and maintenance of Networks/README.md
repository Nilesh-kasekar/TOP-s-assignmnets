# A+ - Understanding and Maintenance of Networks

## 📘 Overview

This repository contains my completed practical and theoretical work for the **A+ – Understanding and Maintenance of Networks** module.

The assignment covers networking hardware, routers and switches, IP configuration, network cables, and basic network testing.

## 📅 Topics Covered

### Day 1 – Introduction to Networking Hardware

* Modem, router, switch, access point and network cables
* Home Wi-Fi network diagram
* Cable types and their uses
* Router vs Switch comparison

### Day 2 – Routers and Switches

* Router and switch functions
* Ports and LED identification
* Router vs Switch differences
* Gaming café network scenario

### Day 3 – Basic Network Configuration

* Router login and default gateway
* IP address, subnet mask and gateway
* DHCP and static IP configuration
* Basic network configuration testing

### Day 4 – Network Cables and Tools

* Ethernet and fiber optic cables
* T568B Ethernet wiring standard
* RJ45 crimper procedure
* Gaming café cable selection

### Day 5 – Network Testing

* Network connectivity testing
* `ping` command
* `tracert` command
* `arp -a` command
* Basic network testing report

## 🔧 Commands Used

```text
ipconfig
ping
tracert
arp -a
```
